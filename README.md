# ShapeSense_AI

AI chat, plans, and workouts use xKiro's Chat Completions API.
Set `XKIRO_API` in `Backend/.env` (or the project root `.env`).
Optionally set `XKIRO_MODEL`; the default is `qwen/qwen3.8-omni-flash:free`.
Environment variables and environment-specific backend configuration take precedence.
See `Backend/.env.example` and https://docs.xkiro.com/.
